What our testers cover

Technical SEO

Crawlability, indexing, canonical tags, structured data, sitemaps, Core Web Vitals and page speed. Findings are ranked by how much they affect search visibility.

Web security

Vulnerability assessment on sites you authorise: security headers, auth flows, input handling, exposed files and access control, reported responsibly.

Software QA

Functional testing, edge cases, cross-browser and mobile checks, and regression passes before you ship.

Performance

Load time, asset weight, caching and render blocking. You get measured numbers and the fixes that move them.

Requirement checks

Every listed tester meets all of these. If one fails, the listing is removed.

To be verified

  • Joined the group and completed the assigned challenges
  • Explained their solutions, not only submitted them
  • Public GitHub profile that can be checked
  • Original work with credit for any shared code
  • Approved by the current verified list

To stay verified

  • Test only inside the written scope
  • No data theft, no exploits against third parties
  • Report every finding with steps to reproduce
  • Disclose responsibly and help fix the issue
  • Keep discussion technical and constructive

How it works

  1. Send a request

    Tell us the site, what you need checked and your deadline. Confirm you own it or are allowed to test it.

  2. Agree the scope

    We match you with a verified tester and write down exactly what can be tested.

  3. Get the report

    Each finding comes with severity, steps to reproduce and a suggested fix.

  4. Fix and retest

    After you patch, the tester confirms the issue is closed.

Questions

How does a tester get verified?

They join the WhatsApp group, complete practical challenges on authorised test targets and submit written reports. Passing the review gets them listed.

Do testers touch my site without permission?

No. Testers only work inside the scope you approve in writing. Unauthorised testing is against the rules and ends a listing.

What do I get at the end of a test?

A written report with each finding, its severity, steps to reproduce it and a suggested fix.

Is it free to join as a tester?

Joining the group and taking the challenges is free.
